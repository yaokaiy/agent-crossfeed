# Code of conduct

This project follows the
[Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be respectful, assume good faith, keep criticism about the work,
and do not harass anyone. This applies in issues, pull requests, discussions
and any other space of this project.

To report a problem, contact the maintainer privately through the
repository's **Security** tab ("Report a vulnerability" also reaches the
maintainer for conduct reports) or through the maintainer's GitHub profile.
Reports are kept confidential.
